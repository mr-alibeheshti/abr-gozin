# راهنمای نیازسنجی ابرگزین

تاریخ بررسی: 2026-10-16

اعداد کف ابرگزین سیاست بررسی اولیه‌اند؛ از عدد منابع نمی‌توان تعداد بازدید یا محصول قابل پشتیبانی را تضمین کرد. WordPress حد ثابت دیسک در صفحهٔ نیازمندی‌ها اعلام نکرده و محدودیت حافظهٔ PHP با رم کل پلن تفاوت دارد.

هاست‌های ۱۰۰MB واقعی از کاتالوگ پاک یا به عدد دیگری تبدیل نمی‌شوند؛ هنگام انتخاب کاربرد ناسازگار از نتایج دقیق و نزدیک کنار گذاشته می‌شوند. ظرفیت اعلام‌نشده برای منبع لازم، سازگار فرض نمی‌شود.

## سایت وردپرسی

کف شروع ابرگزین برای نصب، افزونه، به‌روزرسانی و کمی محتوا: 5GB دیسک و 1GB RAM. این اعداد حداقل رسمی WordPress نیستند؛ حجم واقعی و بار سایت می‌تواند بیشتر باشد.

- سایت وردپرسی‌ات فروشگاهی است، بلاگ است یا معرفی شرکت و خدمات؟
- تقریباً چند مطلب یا صفحه و چه تعداد تصویر داری؟
- حجم فعلی فایل‌ها و دیتابیس و رشدشان چقدر است؛ سایت تازه است یا انتقالی، و بکاپ روی همین فضا می‌ماند؟ اگر نمی‌دانی بگو نامشخص.
- بازدید، درخواست یا کاربر هم‌زمان چقدر است؟ اگر تازه شروع می‌کنی و نمی‌دانی، همان را بگو.
- افزونه یا نیاز خاصی مثل المنتور، چندزبانه، عضویت، فروش فایل یا اتصال حسابداری داری؟ اگر جزئیات را نمی‌دانی بگو.

- [نیازمندی‌های WordPress](https://wordpress.org/about/requirements/): PHP 8.3+، MySQL 8.0+ یا MariaDB 10.11+ و HTTPS؛ این صفحه حد ثابت دیسک اعلام نمی‌کند.
- [راهنمای میزبانی WordPress](https://make.wordpress.org/hosting/handbook/server-environment/#php-memory-limit): حافظهٔ PHP: پیشنهاد معمول 256MB و برای کار سنگین 512MB یا بیشتر؛ این محدودیت با RAM کل هاست یکسان نیست.

## وب‌سایت و میزبانی وب

برای سایت کاملاً استاتیک، حجم واقعی فایل‌ها معیار است و چند گیگابایت حد اجباری نیست. برای سایت پویا، نیاز نرم‌افزار و داده باید مشخص شود.

- سایت فقط HTML/CSS/JS است یا PHP، وردپرس، Node.js یا دیتابیس هم دارد؟
- چند صفحه و چه مقدار تصویر، ویدئو یا فایل قابل دانلود داری؟
- حجم فعلی فایل‌ها و دیتابیس و رشدشان چقدر است؛ سایت تازه است یا انتقالی، و بکاپ روی همین فضا می‌ماند؟ اگر نمی‌دانی بگو نامشخص.
- بازدید، درخواست یا کاربر هم‌زمان چقدر است؟ اگر تازه شروع می‌کنی و نمی‌دانی، همان را بگو.
- فرم، ورود کاربر، ایمیل، SSL، پردازش سمت سرور یا نیاز ویژه‌ای داری؟

- [چک‌لیست استقرار Django](https://docs.djangoproject.com/en/5.2/howto/deployment/checklist/): فایل‌های media، دیتابیس، کش و محیط production باید جداگانه بررسی شوند؛ رم ثابت برای همهٔ پروژه‌ها اعلام نشده است.
- [نیازمندی‌های WordPress](https://wordpress.org/about/requirements/): PHP 8.3+، MySQL 8.0+ یا MariaDB 10.11+ و HTTPS؛ این صفحه حد ثابت دیسک اعلام نمی‌کند.

## داکر و کانتینر

پایهٔ شروع برای سرور Linux با فرض Ubuntu cloud: 1GB RAM و 25GB دیسک. این فقط کف انتخاب است؛ مصرف کانتینرها، imageها، build cache و volumeها جداگانه لازم است.

- چه سرویس‌ها و imageهایی را در Docker اجرا می‌کنی؟
- چند کانتینر هم‌زمان و چه دیتابیس یا کشی کنارشان داری؟
- حجم imageها، build cache و دادهٔ volumeها و بکاپ چقدر است؟ اگر اندازه نگرفته‌ای بگو نامشخص.
- بازدید، درخواست یا کاربر هم‌زمان چقدر است؟ اگر تازه شروع می‌کنی و نمی‌دانی، همان را بگو.
- نیاز به build روی سرور، دسترسی root، پورت خاص، worker یا حد مصرف حافظهٔ مشخص داری؟

- [نیازمندی‌های Ubuntu Server](https://ubuntu.com/server/docs/reference/installation/system-requirements/): برای Ubuntu 24.04 amd64 cloud: حد نصب 1GB RAM و 4GB دیسک؛ فضای پیشنهادی 25GB یا بیشتر. منابع برنامه جداست.
- [منابع کانتینر در Docker Engine](https://docs.docker.com/engine/containers/resource_constraints/): منابع به سرویس‌های داخل کانتینر وابسته است؛ مصرف واقعی باید اندازه‌گیری و محدود شود. نیاز Docker Desktop به سرور تعمیم داده نمی‌شود.

## بک‌اند؛ Node.js یا Django

پایهٔ سرور Linux با فرض Ubuntu cloud: 1GB RAM و 25GB دیسک؛ این مقدار تضمین اجرای پروژه نیست. worker، دیتابیس، کش، آپلودها و بار API باید جدا سنجیده شوند.

- بک‌اند با چه زبان، فریم‌ورک و نسخه‌ای نوشته شده؟
- چند برنامه و worker داری؛ دیتابیس و Redis هم روی همین سرور هستند؟
- حجم فعلی فایل‌ها و دیتابیس و رشدشان چقدر است؛ سایت تازه است یا انتقالی، و بکاپ روی همین فضا می‌ماند؟ اگر نمی‌دانی بگو نامشخص.
- درخواست در ثانیه یا کاربر هم‌زمان چقدر است؛ WebSocket یا کار پس‌زمینه هم داری؟ اگر نمی‌دانی بگو.
- آپلود فایل، پردازش تصویر، صف، cron یا اتصال خارجی خاصی لازم داری؟

- [نیازمندی‌های Ubuntu Server](https://ubuntu.com/server/docs/reference/installation/system-requirements/): برای Ubuntu 24.04 amd64 cloud: حد نصب 1GB RAM و 4GB دیسک؛ فضای پیشنهادی 25GB یا بیشتر. منابع برنامه جداست.
- [اندازه‌گیری حافظه در Node.js](https://nodejs.org/learn/diagnostics/memory/understanding-and-tuning-memory): heap تنها بخشی از مصرف فرایند است؛ مصرف برنامه و workerها باید اندازه‌گیری شود.
- [چک‌لیست استقرار Django](https://docs.djangoproject.com/en/5.2/howto/deployment/checklist/): فایل‌های media، دیتابیس، کش و محیط production باید جداگانه بررسی شوند؛ رم ثابت برای همهٔ پروژه‌ها اعلام نشده است.

## برنامه یا ربات پایتون

پایهٔ Linux با فرض Ubuntu cloud: 1GB RAM و 25GB دیسک. ربات سبک، مرورگر خودکار و مدل یادگیری ماشین مصرف یکسانی ندارند؛ نیاز برنامه باید اندازه‌گیری شود.

- پایتون را برای ربات، وب‌اپ، پردازش داده یا اجرای چه مدل هوش مصنوعی می‌خواهی؟
- چند فرایند یا ربات هم‌زمان داری و هر کار چقدر طول می‌کشد؟
- حجم دیتاست، مدل، فایل‌های موقت و بکاپ چقدر است؟ اگر نمی‌دانی بگو نامشخص.
- چند کار یا کاربر هم‌زمان داری؛ اجرای دائمی است یا زمان‌بندی‌شده؟
- کتابخانه یا نیاز خاصی مثل مرورگر خودکار، GPU/CUDA، دیتابیس یا دسترسی شبکهٔ خاص داری؟

- [نیازمندی‌های Ubuntu Server](https://ubuntu.com/server/docs/reference/installation/system-requirements/): برای Ubuntu 24.04 amd64 cloud: حد نصب 1GB RAM و 4GB دیسک؛ فضای پیشنهادی 25GB یا بیشتر. منابع برنامه جداست.
- [اندازه‌گیری حافظه در Python](https://docs.python.org/3/library/tracemalloc.html): نیاز حافظهٔ برنامه را باید اندازه گرفت؛ نام Python به‌تنهایی ظرفیت سرور را تعیین نمی‌کند.

## پایگاه دادهٔ مستقل

پایهٔ Linux با فرض Ubuntu cloud: 1GB RAM و 25GB دیسک؛ حجم داده، رشد، index، log و بکاپ به این پایه اضافه می‌شوند. این کف ظرفیت عملیاتی دیتابیس را تضمین نمی‌کند.

- چه موتور و نسخه‌ای می‌خواهی؛ PostgreSQL، MySQL/MariaDB، Redis یا چیز دیگر؟
- حجم فعلی داده و indexها چقدر است؛ دیتابیس تازه است یا انتقالی؟
- رشد داده، فضای log/WAL و تعداد بکاپ محلی چقدر است؟ اگر نمی‌دانی بگو نامشخص.
- چند اتصال یا query هم‌زمان و چه نسبتی از خواندن و نوشتن داری؟
- نیاز به replica، دسترس‌پذیری بالا، بازیابی در زمان مشخص یا persistence خاصی داری؟

- [نیازمندی‌های Ubuntu Server](https://ubuntu.com/server/docs/reference/installation/system-requirements/): برای Ubuntu 24.04 amd64 cloud: حد نصب 1GB RAM و 4GB دیسک؛ فضای پیشنهادی 25GB یا بیشتر. منابع برنامه جداست.
- [منابع PostgreSQL](https://www.postgresql.org/docs/current/runtime-config-resource.html): حافظه به shared_buffers، اتصال‌ها و عملیات هم‌زمان بستگی دارد؛ اندازهٔ دیتابیس به‌تنهایی RAM لازم را تعیین نمی‌کند.
- [مصرف حافظهٔ MySQL](https://dev.mysql.com/doc/refman/8.4/en/memory-use.html): بافرهای مشترک و مصرف هر اتصال در حافظهٔ کل مؤثرند.
- [حافظهٔ Redis](https://redis.io/docs/latest/operate/oss_and_stack/management/optimization/memory-optimization/): حجم داده، سربار ساختارها و عملیات روی داده در مصرف حافظه مؤثر است.

## فروشگاه و ظرفیت واقعی

کف اولیهٔ فروشگاه WooCommerce، ۱۰GB دیسک و ۲GB رم پلن است؛ سیاست محافظه‌کارانهٔ ابرگزین است و حداقل رسمی WooCommerce نیست. تعداد محصول، تنوع، تصاویر، دانلود، افزونه‌ها، بار پرداخت، حجم فایل و دیتابیس و رشد باید بررسی شوند. منبع: [WooCommerce](https://woocommerce.com/document/server-requirements/) و [تصاویر محصولات](https://woocommerce.com/document/adding-product-images-and-galleries/).

حجم برنامه و دادهٔ اندازه‌گیری‌شده + رشد در بازهٔ مدنظر کاربر + بکاپ محلی با ۲۵٪ حاشیهٔ سیاستی به پایه اضافه می‌شود. این محاسبه جای اندازه‌گیری log، index، RAM و آزمون بار را نمی‌گیرد. تعداد محصول به ضریب ساختگی GB تبدیل نمی‌شود.

VPS و سرور اختصاصی با کاربرد مشخص، فعلاً با فرض Ubuntu 24.04 cloud سنجیده می‌شوند: کف نصب رسمی ۱GB رم و ۴GB دیسک و دیسک پیشنهادی ۲۵GB است؛ کف انتخاب ما ۲۵GB دیسک است و منابع برنامه جداگانه باید سنجیده شوند. Windows و سیستم‌عامل دیگر نیاز به بررسی جدا دارد.

چت قبل از پیشنهاد نوع دقیق پروژه، تعداد/مقیاس، حجم و رشد و بکاپ، بار و نیازهای ویژه و بودجه را می‌پرسد. پاسخ صریح «نمی‌دانم» معتبر است و نیاز به اندازه‌گیری را نشان می‌دهد؛ با صفر جایگزین نمی‌شود. GPU/VRAM در کاتالوگ تأیید نشده و پیشنهاد سازگار برایش داده نمی‌شود. نسخهٔ runtime و جزئیات میزبانی باید از ارائه‌دهنده تأیید شوند.

برای Redis و اجرای مدل AI، تا نیاز RAM از مستندات همان پروژه یا اندازه‌گیری مشخص نشده، پیشنهاد پلن متوقف می‌ماند. برای Redis از INFO memory و اوج مصرف کمک بگیر؛ اندازهٔ فایل ذخیره‌شده با حافظهٔ لازم یکسان نیست.
