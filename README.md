# ابرگزین — ترب هاست و سرور

محصول فارسی برای جست‌وجو و مقایسهٔ پیشنهادهای هاست و سرور، با دادهٔ واقعی از صفحات رسمی ارائه‌دهنده‌ها، فونت محلی Peyda و رابط RTL.

## اجرا

نسخهٔ آماده روی این دستگاه: **http://localhost:4321**

به Node.js 24 یا جدیدتر نیاز دارد. از همین پوشه:

```sh
npm ci
npm run build
npm start
```

برای توسعه:

```sh
npm run dev
```

روی macOS، فایل `start.command` همین پوشه هم نسخهٔ ساخته‌شده را اجرا می‌کند. اگر پورت ۴۳۲۱ قبلاً در حال اجرا باشد، برنامهٔ موجود را باز می‌کند. برای توقف اجرای ترمینالی، Control+C را بزنید.

متغیرهای اختیاری: `PORT` (پیش‌فرض 4321)، `DATA_DIR` (پیش‌فرض data)، `MODEL_CACHE_DIR` (پیش‌فرض data/models)، `NO_REFRESH=1` (صرفاً جلوگیری از دریافت اولیه هنگام شروع).

## قابلیت‌ها

- فرم یکپارچهٔ «مشخصات مورد نظرت را انتخاب کن» بدون ورودی متن: نوع سرویس، کاربرد (داکر، بک‌اند، پایتون، پایگاه داده، وردپرس یا وب‌سایت)، موقعیت، منابع، ارائه‌دهنده، بودجه، ترافیک، IPv4 و مرتب‌سازی همگی در همان فرم‌اند. انتخاب کاربرد نوع سرویس را تنظیم می‌کند؛ تغییر به نوع ناسازگار، کاربرد را پاک می‌کند. نتایج با هر انتخاب به‌روز می‌شوند.
- کاربرد فقط نوع زیرساخت را محدود می‌کند و منابع یا پشتیبانی نرم‌افزار فرضی تولید نمی‌کند. لینک‌های قبلی با عبارت فارسی به انتخاب‌های فرم تبدیل می‌شوند. API استخراج فارسی و مدل چندزبانهٔ MiniLM را برای لینک‌ها و مصرف‌کنندگان قبلی حفظ می‌کند.
- انتخاب مقدار دقیق RAM، دیسک و CPU از ظرفیت‌های واقعی موجود، همراه فیلتر نوع سرویس، کشور، ارائه‌دهنده و سقف هزینه. نتایج مطابق انتخاب، قبل از پیشنهادهای نزدیک نمایش داده می‌شوند.
- پیشنهادهای نزدیک از پلن‌های واقعی انتخاب می‌شوند و اختلاف هر منبع روی کارت و در جزئیات می‌آید. هر منبع انتخاب‌شده باید مشخص باشد و در بازهٔ نصف تا دو برابر درخواست باشد؛ فاصلهٔ نسبی منابع، ترتیب نزدیکی را تعیین می‌کند و مرتب‌سازی انتخابی در تساوی نزدیکی اعمال می‌شود. حداکثر ۹ پیکربندی نزدیک نمایش داده می‌شود. کشور، ارائه‌دهنده، نوع سرویس و سقف برآورد هزینه در این بخش نیز رعایت می‌شوند؛ یک پلن هم‌زمان در دو بخش نمی‌آید.
- گروه‌بندی بر اساس نوع سرویس، کشور و ظرفیت اسمی CPU/RAM/دیسک؛ تفاوت SSD/NVMe، اشتراک منابع و مدیریت سرویس در جزئیات باقی می‌ماند.
- محاسبهٔ هزینهٔ ماهانه با ترافیک انتخابی، یک IPv4 و فقط مالیات یا هزینه‌های مشخص در منبع.
- ذخیره و مقایسهٔ حداکثر سه پیکربندی با ماندگاری در SQLite و کوکی HttpOnly همان مرورگر؛ دریافت جدول CSV و کپی لینک جست‌وجو.
- نمایش منبع، تاریخ تأیید تعرفه، خطای دریافت، سوابق واقعی تغییر قیمت و مراجعه به سایت رسمی برای خرید.
- به‌روزرسانی در شروع برنامه و هر شش ساعت؛ بررسی دستی با محدودیت زمانی و حفظ اطلاعات قبلی در خطا.

پوشش فعلی شامل **۱۹۸ پلن یا پیکربندی از ۲۰ فروشندهٔ مستقل** است؛ ۱۲ مورد، پیکربندی محاسبه‌شدهٔ آروان هستند. هر فروشنده دارای پلن و قیمت واقعی در پایگاه داده است. این محصول پوشش تمام بازار، کیفیت، موجودی لحظه‌ای یا آپتایم مستقل را ادعا نمی‌کند. کاربران خرید را در سایت ارائه‌دهنده انجام می‌دهند. روی کارت‌های نتایج و در «پیشنهادهای ارائه‌دهنده‌ها»، لوگوی اصلی هر ۲۰ فروشنده از فایل محلی نمایش داده می‌شود؛ نشانی منبع هر فایل در `public/logos/sources.json` ثبت شده است. نشان آروان از نسخهٔ ثبت‌شده در ویکی‌مدیا گرفته شده چون دریافت سایت رسمی در این شبکه محدود است. لوگوهای کوچک کارت‌های نتایج از نشان یا آیکون رسمی برند استفاده می‌کنند؛ در فهرست منابع و جدول مقایسه هم لوگوها نمایش داده می‌شوند. اگر تصویر بارگذاری نشود، همان نشان شناسایی جایگزین می‌شود.

پیکربندی‌های آروان نام پلن تبلیغ‌شده نیستند؛ از تعرفهٔ CPU، RAM و SSD محاسبه می‌شوند. سهمیهٔ ۲۵۰ GB آروان به مجموع حساب تعلق دارد؛ برآورد فعلی حساب بدون مصرف قبلی را فرض می‌کند. ترافیک باید طبق تعریف جهت صورتحساب هر ارائه‌دهنده تفسیر شود.

منابع اعلام‌نشده با `null` ذخیره می‌شوند. مالیات نامشخص به مبلغ اضافه نمی‌شود و هشدار دارد. رقم ماهانهٔ برخی پلن‌ها معادل پرداخت سه‌ماهه، شش‌ماهه یا سالانه است؛ دوره و مبلغ پایهٔ پرداخت با مالیات اعلام‌شده نیز نمایش داده می‌شوند. کوتاه‌ترین دورهٔ منتشرشده انتخاب شده؛ هرجا فقط تعرفهٔ سالانه منتشر شده، همان دوره ثبت شده است. واحد مگابایت فضای هاست با مبنای ۱۰۰۰ به گیگابایت تبدیل شده؛ RAM میهن وب هاست و آذرآنلاین با مبنای ۱۰۲۴ تبدیل شده است. بیش‌مصرف با تعرفهٔ نامشخص، برآورد کامل ندارد. مدل فقط نوع سرویس را تطبیق می‌دهد و مبلغ، کیفیت یا موجودی تولید نمی‌کند.

قیمت ایران‌هاست در صفحه به میلیون تومان گرد شده و همان رقم نمایش‌داده‌شده ثبت شده است. فید عمومی میهن هاستینگ فقط به‌عنوان دادهٔ متنی خوانده می‌شود؛ هیچ اسکریپت فروشنده اجرا نمی‌شود. محل سرویس آن بین ایران و اروپا تفکیک نشده و `unknown` باقی می‌ماند. اطلاعیهٔ فعلی PAYG وب‌داده با ۱۰۰GB جدول ناسازگار است؛ سهمیهٔ رایگان در برآورد آن لحاظ نشده و توضیح کنار پیشنهاد آمده است. سه پلن تکمیل‌ظرفیت میهن وب هاست وارد پیشنهادهای قابل خرید نشده‌اند.

از صفحهٔ منابع می‌توان کل تعرفه‌ها را به CSV یا JSON دریافت کرد. برای ذخیرهٔ خروجی فایل نیز `npm run export:catalog` را اجرا کن؛ فایل‌ها در پوشهٔ خروجی یک سطح بالاتر ساخته می‌شوند. JSON شامل منابع، تاریخ تأیید، شاهد متنی استخراج و هش منبع است. `exportedAt` صرفاً تاریخ خروجی است.

## ساختار و داده‌ها

React/TypeScript/Vite برای رابط؛ Express و SQLite داخلی Node برای سرور؛ Cheerio برای استخراج HTML. مقصدهای دریافت و تغییر مسیر به دامنه‌های ثابت رسمی محدودند. ورودی‌ها با Zod اعتبارسنجی می‌شوند و درخواست‌های تغییر وضعیت فقط از مبدأ محلی برنامه پذیرفته می‌شوند.

`data/abrgozin.sqlite` شامل پیشنهادها، وضعیت منابع، ذخیره‌های هر نشست و سوابق تغییر قیمت است. برای انتقال فقط کد، دادهٔ اولیه کافی است؛ کوکی و ذخیره‌های خصوصی مرورگر را همراه نمونهٔ عمومی منتشر نکنید. مدل دانلودشده در `data/models` حدود ۱۴۰ MB است. اگر کش مدل موجود نباشد، کتابخانه هنگام اولین شروع آن را دریافت می‌کند. شکست دریافت مدل، جست‌وجوی مشخصات و واژه‌ها را غیرفعال نمی‌کند.

افزودن منابع جدید به دیتابیس موجود فقط داده‌های همان منابع را اضافه می‌کند و ذخیره‌های نشست، تاریخچهٔ قیمت و نتیجهٔ قبلی سایر منابع را حفظ می‌کند.

## اعتبارسنجی

```sh
npm test
npm run build
```

تست‌ها، استخراج از HTML واقعی ثبت‌شده، محاسبهٔ تعرفه، بودجه و ارقام فارسی، ماندگاری نشست، اتمیک بودن تغییر منبع، حفظ زمان تأیید در خطای دریافت، اعتبارسنجی API و اجرای واقعی مدل را پوشش می‌دهند. فایل‌های HTML در `server/fixtures` فقط نمونهٔ دریافت‌شده برای تست‌اند و دستور اجرایی محسوب نمی‌شوند.

جست‌وجو، ذخیره پس از بارگذاری مجدد، مقایسه، دانلود CSV، جزئیات قیمت، پرداخت دوره‌ای، بررسی دستی منابع، Escape در پنجره‌ها و نمایش در عرض حدود ۳۹۰ پیکسل و دسکتاپ در مرورگر بررسی شده‌اند.

## انتشار

این نسخه روی **127.0.0.1** اجرا می‌شود و انتشار عمومی یا دامنهٔ عمومی ندارد. برای استقرار روی سرور، همین برنامهٔ Node، دیسک پایدار برای SQLite و پروکسی HTTPS لازم است؛ فهرست مبدأهای مجاز باید متناسب با دامنهٔ مقصد پیکربندی شود. برای چند نمونهٔ هم‌زمان، SQLite محلی باید با ذخیره‌سازی مشترک مناسب جایگزین شود.
